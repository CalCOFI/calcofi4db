# Stop when [`check_stac()`](https://calcofi.io/calcofi4db/reference/check_stac.md) found an error

Stop when
[`check_stac()`](https://calcofi.io/calcofi4db/reference/check_stac.md)
found an error

## Usage

``` r
assert_stac(d, quiet = FALSE)
```

## Arguments

- d:

  the tibble from
  [`check_stac()`](https://calcofi.io/calcofi4db/reference/check_stac.md)

- quiet:

  suppress the summary line

## Value

`d`, invisibly.
