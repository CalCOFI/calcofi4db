# Deepest plausible sample depth in the CalCOFI region, metres

The abyssal plain under the westernmost historical stations (~158°W) is
~5,500 m and the region has no trench; 6,500 m matches the ceiling
already declared on `pressure` (6,500 dbar). A depth beyond it is an
error, not an observation.

## Usage

``` r
CC_DEPTH_MAX_M
```

## Format

An object of class `numeric` of length 1.
