# Write a sitemap XML file (sitemaps.org 0.9)

Write a sitemap XML file (sitemaps.org 0.9)

## Usage

``` r
write_sitemap_xml(d, path)
```

## Arguments

- d:

  the tibble from
  [`build_datasets_sitemap()`](https://calcofi.io/calcofi4db/reference/build_datasets_sitemap.md)

- path:

  the file to write

## Value

`path`, invisibly.
