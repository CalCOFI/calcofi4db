# Summarise a netCDF plan as one row

Convenience for the generic publish notebook, which reports a table of
every dataset it is about to write.

## Usage

``` r
summarise_netcdf_plan(plan)
```

## Arguments

- plan:

  A
  [`plan_dataset_netcdf()`](https://calcofi.io/calcofi4db/reference/plan_dataset_netcdf.md)
  result

## Value

A one-row tibble
