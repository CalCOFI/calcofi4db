# Stop when a Darwin Core check found an error

Stop when a Darwin Core check found an error

## Usage

``` r
assert_dwc(d, quiet = FALSE)
```

## Arguments

- d:

  the frame from
  [`dwc_check()`](https://calcofi.io/calcofi4db/reference/dwc_check.md)

- quiet:

  suppress the printed summary

## Value

`d`, invisibly.
