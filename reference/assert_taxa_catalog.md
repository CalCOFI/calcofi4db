# Stop on any failing check from [`check_taxa_catalog()`](https://calcofi.io/calcofi4db/reference/check_taxa_catalog.md)

Stop on any failing check from
[`check_taxa_catalog()`](https://calcofi.io/calcofi4db/reference/check_taxa_catalog.md)

## Usage

``` r
assert_taxa_catalog(d, quiet = FALSE)
```

## Arguments

- d:

  the table from
  [`check_taxa_catalog()`](https://calcofi.io/calcofi4db/reference/check_taxa_catalog.md)

- quiet:

  suppress the passing summary

## Value

`d`, invisibly, when nothing blocks.
